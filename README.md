# firmware-ota-java（设备侧）

以本地目录模拟设备存储与升级包来源的固件升级服务（Spring Boot）。

- 升级包解析与校验（清单缺失、篡改、型号/硬件不匹配等**可区分拒绝原因**）
- 分块 SHA-256 校验的**断点续传**（未通过校验的数据绝不使用）
- A/B 双槽 + 原子 layout 切换，**任意时刻掉电都落在完整可用版本**
- 新版本启动自检（失败/超时自动回滚），回滚记录追加持久、不被后续升级删除
- 可配置降级策略与最低兼容版本、包大小与存储占用上限
- 升级/查询/回滚串行化，`upgradeId` 幂等，拒绝重复写入
- 26 个测试覆盖中断、掉电、校验失败、自检超时、非法包、并发与空间超限

详见 [docs/OTA.md](docs/OTA.md)（包格式、状态模型、兼容与回滚规则、配置项、接口、本地验证）。

快速开始：

```bash
mvn test            # 运行全部测试
mvn spring-boot:run # 启动，空存储自动预置出厂固件 1.0.0
```
